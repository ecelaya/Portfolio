# Eloy Celaya López — Portfolio

Personal portfolio site built with Astro. Covers experience, education, skills, certifications, and contact.

## Stack

- [Astro](https://astro.build) v7 (minimal template, TypeScript strict)
- Vanilla CSS with custom properties — no UI framework
- Fonts: DM Sans · Space Grotesk · JetBrains Mono

## Dev

```bash
npm install
npm run dev        # localhost:4321
npm run build
npm run preview
```
